# Theta Power Systems — Website Redesign (Protótipo)

Protótipo de redesign da home page de [thetapowersys.com](https://thetapowersys.com), usando os assets de marca reais (logo e diagrama DTFC).

## Rodar localmente

Não precisa de build nem dependências — é HTML/CSS/JS puro.

Abra `index.html` diretamente no navegador, ou sirva localmente:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Estrutura

```
theta-website/
├── index.html              # página única do protótipo
├── assets/
│   ├── logo.png             # logotipo com fundo transparente
│   └── dtfc-vector-control.png   # diagrama técnico DTFC
└── README.md
```

## Publicar no GitHub Pages

1. Suba este conteúdo para um repositório no GitHub.
2. Vá em **Settings → Pages**.
3. Em "Build and deployment", selecione a branch `main` e a pasta `/ (root)`.
4. Salve — o GitHub gera uma URL do tipo `https://seu-usuario.github.io/nome-do-repo/`.
